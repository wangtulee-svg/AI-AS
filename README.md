## 📌 Overview
An AI-powered web application that helps university students with:
- 🤖 Intelligent Chatbot for academic queries
- 📄 PDF summarization and analysis
- 📝 Automatic quiz generation
- 📚 Timetable recommendations
- 📊 Personalized student dashboard

## 🚀 Tech Stack
- **Frontend**: React 18, TailwindCSS, Framer Motion
- **Backend**: Node.js, Express.js, Socket.io
- **Database**: MySQL 8.0
- **AI/ML**: Python, OpenAI GPT-4, LangChain, PyPDF2
- **DevOps**: Docker, GitHub Actions, AWS
